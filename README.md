🐍 Snake Water Gun Game

A fun Snake Water Gun game built using Python and Tkinter.

Features

- 🎮 Interactive graphical user interface
- 🐍 Snake, Water and Gun choices
- 🤖 Random computer opponent
- 🏆 Live score tracking
- 🔄 Reset button

Technologies Used

- Python
- Tkinter
- Random module

How to Run

1. Install Python 3.
2. Clone this repository.
3. Run the following command:

python3 snake_water_gun.py
